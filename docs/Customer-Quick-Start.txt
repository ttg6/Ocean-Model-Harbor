Ocean 模型港 1.0.8 客户使用说明

首次使用的详细步骤和常见问题处理，请阅读同目录的“使用教程.txt”。

一、运行程序
适用系统：Windows 10 / 11，64 位。
1. 将整个压缩包解压到一个文件夹。
2. 进入 Ocean 模型港 文件夹，双击 Ocean 模型港.exe。
3. 程序已经包含运行环境，无需另行安装 Java。
请保留同目录下的 app 和 runtime 文件夹，程序依赖它们运行。

二、首次设置
1. 打开“供应商与账号”，选择您使用的供应商并登录自己的账号。
   Trae：选择 Trae，点击“浏览器登录”直接授权添加账号，可重复添加多个不同账号。
         添加其他账号前，请先在浏览器中退出当前 Trae 账号，再登录另一个账号完成授权。
         同一账号重复授权会更新原账号，不会新增一条账号记录。
         新用户可以点击“TRAE 邀请注册”，完成注册后回到工具点击“继续授权”。
   Antigravity：先在“更多操作 → Antigravity OAuth 配置”填写自己的 Client ID / Client Secret，再浏览器登录。更换客户端需要重新授权。
   WorkBuddy：浏览器授权，选择账号对应的国内版或国际版。
   Loomy：手机号与短信验证码登录。
   自定义 OpenAI 中转站：添加中转站，填写 Base URL、API Key 和模型列表。
2. 打开“模型”，点击“刷新目录”，选择模型并复制完整模型 ID。
   目录中可能包含内置模型快照；是否能调用取决于账号权限和剩余额度。
3. 回到“网关”，点击“启动网关”。

三、接入 ZCode
1. 在 ZCode 的模型设置中添加自定义供应商，名称可填写 Ocean 模型港。
2. 协议选择 OpenAI Chat Completions。
3. OpenAI Base URL 填写：http://127.0.0.1:8790/v1
4. API Key：网关默认允许无 Key 调用，可填写 sk-local-gateway。
   如果您在网关设置中关闭了无 Key 调用，请填写自己设置的网关 API Key。
5. 手动添加模型，填入从网关“模型”页复制的完整模型 ID。
   例如：trae/glm-5.3-flash（需要已登录的 Trae 账号有该模型权限）。
6. 保存并启用供应商和模型，在对话框的模型选择器中选择该模型。
其他支持 OpenAI 兼容协议的客户端，也可以使用相同的地址和模型 ID。

四、日常使用
左侧导航可切换五个页面，首页也提供“管理账号”“查看模型”“接入设置”快捷入口。
账号页的删除、任务和供应商编辑等操作位于“更多操作”或“更多账号操作”菜单。
设置分为“网关与访问”“网络代理”“偏好与数据”，点击左侧分类可跳转，也可搜索设置项。
点击“保存设置”或按 Ctrl+S 应用全部修改。“放弃修改”还原当前保存的配置。
“恢复默认值”与“重新生成”API Key 只修改草稿，保存后生效。修改 Key 后请同步更新客户端。
“测试代理端口”检查填写地址的 TCP 可连接性，上游模型调用结果请在模型页验证。
使用客户端时请保持网关正在运行。
关闭网关窗口后，程序会继续在系统托盘运行；双击托盘图标可打开窗口。
右键托盘图标会在图标旁弹出快捷控制窗口，显示网关状态与接口地址。
可选择“打开 Ocean 模型港”“启动网关”或“停止网关”；
选择“退出程序”会关闭程序和网关。点击窗口外部或按 Esc 可收起快捷控制窗口。
默认仅允许本机连接。需要局域网连接时，可在设置中开启，并使用网关电脑的局域网地址。

五、常见问题
连接失败：确认网关已启动，客户端的协议、地址与监听端口填写正确。
404 或未知路径：检查客户端是否选择 OpenAI Chat Completions 协议。
401：检查客户端填写的网关 API Key 与网关访问设置。
503 或无可用账号：登录对应供应商账号，检查账号是否启用、凭证是否有效。
额度不足：在“供应商与账号”中刷新额度，按上游服务的规则处理。
模型无法调用：复制完整模型 ID，并确认该供应商账号拥有调用权限。
可在网关的“调用记录”页面查看失败原因。

六、账号与数据
本交付包包含程序、运行环境和许可证；首次使用需要您自行登录或添加服务账号。
账号与设置通过 Windows 用户加密保存，默认目录为：
%LOCALAPPDATA%\AI Gateway Windows
数据目录沿用旧版，更新名称后已有账号与设置仍可继续使用。
模型服务的可用性和额度由上游供应商决定。
