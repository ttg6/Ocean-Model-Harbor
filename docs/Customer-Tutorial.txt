Ocean 模型港使用教程
适用版本：Windows 1.0.12

1.0.12 更新说明：修复 WorkBuddy 流式响应携带空工具调用数组，导致 ZCode 每个思考片段都重复创建条目的问题。真实思考内容、正文和工具调用继续保留。先退出旧版托盘程序，再打开新版；已生成的重复记录不自动清除，建议新建对话验证。

首次使用顺序：解压运行 → 登录账号 → 选择模型 → 启动网关 → 配置客户端。
本文以 TRAE 账号和 ZCode 客户端为例。

一、解压并打开软件

1. 使用 Windows 10 / 11 的 64 位电脑。
2. 右键客户 ZIP 压缩包，选择“全部解压”，等待解压完成。
3. 打开解压后的“Ocean 模型港”文件夹，双击“Ocean 模型港.exe”。
4. 程序自带 Java 运行环境，无需另行安装 Java。

请完整保留程序目录，尤其是 app 和 runtime 文件夹。建立快捷方式时，
右键 EXE 创建快捷方式即可，程序本体仍留在完整目录中。

首次启动时，账号列表为空。需要登录自己的模型服务账号或添加自己的中转站。

二、认识五个页面

网关：查看服务状态、启动或停止网关、复制接入地址。
供应商与账号：登录账号、添加中转站、管理账号启用状态、刷新额度。
模型：刷新模型目录、搜索模型、复制完整模型 ID、测试模型延迟。
调用记录：查看请求结果、耗时和错误信息。
设置：调整端口、访问 Key、网络代理、运行偏好和日志保留时间。

三、登录 TRAE 账号

1. 点击左侧“供应商与账号”。
2. 在上方供应商表格中选中 Trae。
3. 点击“浏览器登录”。
4. 在打开的浏览器中登录自己的 TRAE 账号，完成页面提示的授权。
5. 回到 Ocean 模型港，确认下方“账号池”出现账号记录。
6. 点击“刷新额度”，检查账号状态和额度信息。

新用户可以点击“TRAE 邀请注册”，完成注册或登录后，回到工具点击
“继续授权”，再完成接入。已有账号可直接使用“浏览器登录”。
授权最多等待 5 分钟；超时后重新点击“浏览器登录”。

添加第二个或更多 TRAE 账号：
1. 先在浏览器中退出当前 TRAE 账号，切换到另一个账号。
2. 在本工具中再次选中 Trae，点击“浏览器登录”。
3. 完成授权后，检查账号池是否新增账号记录。

同一账号重复授权会更新已有记录，不会新增第二条相同账号。
账号显示“已停用”时，选中它并点击“启用 / 停用账号”。
供应商本身也需要处于启用状态，可通过“更多操作”管理。
“需重新登录”表示该账号需要重新完成授权；额度显示未知时，可先刷新额度。

其他供应商：
Antigravity 先在“更多操作 → Antigravity OAuth 配置”填写自己的 Google 桌面应用 Client ID / Client Secret，再浏览器登录；更换 OAuth 客户端需要重新授权，账号服务权限仍由上游决定。WorkBuddy 登录时需选择账号对应的国内版或国际版；
Loomy 使用“短信登录”，按提示填写手机号与验证码。

四、选择模型并复制模型 ID

1. 点击左侧“模型”。
2. 点击“刷新目录”，等待刷新完成。
3. 用搜索框查找需要的模型。
4. 在表格中选中模型，点击“复制模型 ID”。

请使用复制得到的完整 ID，它通常包含供应商前缀。
例如：如果目录中实际出现 trae/glm-5.3-flash，就完整复制这串文字。
目录可能包含内置模型快照；是否能调用取决于账号权限、额度和上游可用性。

“测试延迟”会执行实际模型请求，可能消耗上游额度，按需使用。
首次接入可先选择一个确认有权限且有额度的模型。

五、启动本地网关

1. 回到“网关”页面，点击“启动网关”。
2. 确认页面显示“网关正在运行”。
3. 点击“复制地址”，得到当前的 OpenAI 接入地址。

默认地址为：http://127.0.0.1:8790/v1
如果修改过端口，以软件首页实际显示的地址为准。

使用 AI 客户端期间，请保持网关运行。账号登录成功和网关运行是两个步骤，
需要分别完成。首页的“可用 / 全部账号”统计可用于检查账号池。

六、接入 ZCode

在 ZCode 中打开自定义模型或供应商的配置入口，具体名称以客户端版本为准。
新建供应商，按以下内容填写：

供应商名称：Ocean 模型港（名称可自定义）
协议类型：OpenAI Chat Completions
OpenAI Base URL：http://127.0.0.1:8790/v1，或本工具首页复制的实际地址
API Key：默认允许无 Key 调用时，可填写占位值 sk-local-gateway
模型 ID：从 Ocean 模型港“模型”页复制的完整模型 ID

如果在本工具的“设置”中关闭了“允许无 Key 调用”，请在 ZCode 中填写
自己设置的网关 API Key。这里填写的是本地网关的访问 Key。

配置步骤：
1. 保存供应商配置。
2. 手动添加需要使用的模型，填写完整模型 ID。
3. 启用供应商和模型。
4. 在 ZCode 的对话或任务界面中选择刚添加的模型。
5. 发送一条简短消息，例如“你好，请回复连接成功”。
6. 回到 Ocean 模型港的“调用记录”页面，查看这次请求的结果。

只有接入地址、没有添加和选择模型时，客户端仍可能无法调用。
若 ZCode 的配置项没有上述协议，请选择其支持 OpenAI Chat Completions
的自定义接入方式。其他兼容客户端也可使用同样的地址、Key 和模型 ID。

七、添加自定义 OpenAI 中转站（可选）

如果使用自己的 OpenAI 兼容服务：
1. 打开“供应商与账号”，点击“添加中转站”。
2. 填写标识，例如 myrelay；填写一个便于辨认的名称。
3. Base URL 填写上游服务商提供的兼容接口地址。
4. API Keys 填写上游服务商提供的 Key，每行一个。
5. 模型名称每行一个，也可填写 Key 后点击“读取上游模型目录”。
6. 确认保存，回到“模型”页面刷新目录并复制完整模型 ID。
7. 客户端继续连接本地网关地址，选择刚添加的中转站模型。

上游 API Key 在“添加中转站”中填写；本地网关访问 Key 在客户端中填写。
两处分别对应上游服务和本机网关的访问设置。

八、常用设置与托盘操作

修改端口或访问 Key：
打开“设置”→“网关与访问”，修改后点击“保存设置”，或按 Ctrl+S。
随后按首页实际地址和保存的 Key 更新客户端配置。
“恢复默认值”和“重新生成”API Key 先修改草稿，需要保存才会应用。
“放弃修改”恢复当前已保存的配置。

配置网络代理：
打开“设置”→“网络代理”，填写自己实际使用的代理类型、地址和端口。
“测试代理端口”仅检查 TCP 端口可连接性；模型是否可用需通过实际调用验证。

自动启动网关：
打开“设置”→“偏好与数据”，开启“程序启动时启动网关”并保存。
这表示打开本程序时自动启动网关。

系统托盘：
关闭主窗口后，程序继续在右下角系统托盘运行。
找不到图标时，点击任务栏的“显示隐藏的图标”。
双击海锚图标可以打开主窗口。
右键图标会在旁边弹出快捷控制窗口，可打开主窗口、启停网关或退出程序。
点击窗口外部或按 Esc 可收起快捷控制窗口。
“退出程序”会同时停止网关，客户端随后无法继续通过它调用。

九、常见问题

1. 客户端连接失败或提示 connection refused
   确认 Ocean 模型港已打开，网关显示正在运行；核对当前端口和接入地址。
   检查是否已经从托盘退出了程序。

2. 添加了接入地址，但仍无法发送消息
   检查是否添加、启用并选择了模型；模型 ID 使用模型页复制的完整内容。

3. 401 或鉴权失败
   检查网关是否允许无 Key 调用；关闭该选项时，客户端需填写保存的网关 Key。
   如果上游返回鉴权失败，检查对应账号或中转站 Key，并查看调用记录详情。

4. 404 或未知路径
   检查客户端使用的协议是否为 OpenAI Chat Completions，Base URL 是否与
   网关首页的接入地址一致。查看调用记录判断错误来自网关还是上游。

5. 未知模型或模型无法使用
   刷新目录后重新复制完整模型 ID；确认供应商已启用，账号具有该模型权限。

6. 503、无可用账号或额度不足
   检查供应商与账号的启用状态，刷新额度；需要重新登录的账号重新授权。
   上游的额度与限速仍然有效，多个账号不会产生永久无限额度。

7. 添加其他 TRAE 账号后，账号数量没有增加
   检查浏览器是否仍登录同一账号；先切换账号，再重新完成浏览器授权。

8. 网关无法启动或提示端口被占用
   在设置中更换一个未被占用的端口，保存后启动网关，并更新客户端地址。

9. 需要另一台局域网电脑连接
   在网关设置中开启“允许局域网连接”，配置网关访问 Key 并保存。
   另一台电脑使用网关电脑的局域网 IP 和实际端口，而非 127.0.0.1。
   无法连接时检查两台电脑的网络与防火墙设置。

十、更新软件与本地数据

更新时先从旧版托盘选择“退出程序”，将新版压缩包完整解压到新文件夹，
再启动新版 EXE。已有桌面快捷方式需要指向新版 EXE。

默认账号、设置和调用记录保存在：%LOCALAPPDATA%\AI Gateway Windows
可以在软件中点击“打开数据目录”查看。
账号与设置受 Windows 用户加密保护；更换电脑或 Windows 用户后重新登录账号。

Token 自动计算（1.0.12）
首页默认开启自动计算，无需填写换算比例。
正常通过网关使用 TRAE：首次完整调用建立基准，后续完整调用累计至少 2 积分扣减后开始估算。
未选择模型时，首次完整调用后自动选中；也可选择要查看的模型。
点击“测算详情”，查看实际 Tokens、积分扣减和自动计算的比例。
如果全部账号没有对话余额，首页会显示已有的“权益包参考积分”，明确标注来源；参考积分不会自动换算 Tokens。收到对话余额后自动恢复。
按账号、模型和忙闲时段分别测算；只汇总已有有效样本的可用账号。
并发、失败、中断、缺失数据、积分增加等异常区间不纳入测算。
没有足够数据时显示“采集样本中”；软件不会主动发起额外测试。测算详情会显示缺少用量、缺少对话积分余额、请求中断或等待扣分等具体状态。如果上游未回报必要数据，增加调用次数也不能计算。
默认使用最近对话余额；签到、充值和外部消费需下一次计费回报同步。
累计用量只覆盖本网关回报 usage 的调用。预计值仅供参考，不代表上游承诺额度。
