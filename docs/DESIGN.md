# Windows 桌面界面

面向在本机使用 Cherry Studio、Cline 等工具的用户，主要任务是登录账号、启停网关、复制接入信息和排查调用。

颜色：深海蓝 `#102C43` 用于侧边导航与标题；海港青 `#086F82` 用于主要操作和运行状态；雾蓝 `#EAF1F5` 用于工作区背景；白色用于表格和接入面板；灰蓝 `#597587` 用于说明文本；冰青 `#AEF5E9` 用于当前导航。

字体：Microsoft YaHei UI 用于中文界面，Consolas 用于接入地址。标题 19–27px，正文 13px。使用 FlatLaf 的键盘焦点、Windows HiDPI 缩放与表格控件。

布局：灯塔横幅下使用固定侧边导航与可切换的明亮工作区。首页把运行状态与接入地址放在同一个面板，下方用一条分隔的数据栏显示真实统计，再以三个有顺序的步骤说明客户端接入。账号页保留上下两个表格，常用动作直接显示，其他操作收进中文菜单。模型页提供搜索与清除按钮，日志页把调用记录和深海蓝运行控制台分开，设置页按网关访问、网络代理、偏好数据分类并固定保存入口。

1.0.4 顶部横幅使用深海蓝 `#102D43`、海港青 `#0A6071`、冰青 `#62D9D2` 与雾白 `#BFD5DF`。右侧灯塔、码头和汇聚的水面光线呼应「模型港」，左侧留白用于真实中文字体绘制品牌名及功能说明。背景作为 JAR 资源内置，按窗口尺寸裁切缩放；文字独立绘制以保证 HiDPI 清晰度。托盘右键菜单使用 Swing 和显式 Microsoft YaHei UI 字体，提供中文按钮、键盘操作及窗口外点击关闭。

审查：采用熟悉的 Windows 桌面导航，避免把配置堆成重复卡片。空目录提示刷新和登录，额度未知显示「未知」，不编造账号、模型延迟或成功状态。

1.0.5 统一按钮层级、表头、行距、交替行背景、状态文字颜色和无内容引导。默认窗口 1280×880，最小窗口 940×650；首页和设置内容跟随可视宽度并可纵向滚动，表格保留分隔条调整高度。所有网络调用保持在后台执行，TRAE 邀请入口继续独立于浏览器授权。

1.0.6 以用户导出的 Stitch HTML 为视觉依据，设计参考留在 `stitch/settings-reference.html`（公开版示例 Key 已替换为明确的占位文本）。采用原稿的深海蓝 `#102C43`、浅冰蓝 `#F5FAFF`、海港青 `#00687A`、输入底色 `#E9F5FF`、冰青 `#A9F0E4` 和白色。顶部改为 100px 的紧凑品牌与真实服务状态栏，保留 Windows 原生标题栏；侧栏改为紧凑行和冰青选中指示线。其余页面沿用统一圆角面板、按钮和输入样式。

设置页按原稿采用左侧分类锚点、右侧可滚动设置组、双栏说明与输入、真实开关、搜索和固定底部操作。生成 Key 使用 SecureRandom，显示/隐藏与复制可用，保存与 Ctrl+S 调用原网关配置逻辑；恢复默认值仅填充草稿，放弃修改重读已保存配置。代理检查执行实际 TCP 连接并明确检查范围。运行状态、堆内存与线程数来自引擎和 JVM，原稿的示例版本、样例密钥、随机延迟和 Goroutines 文案未作为运行事实采用。账号和数据不随视觉更新迁移或清空。程序无需联网加载 Tailwind、网页字体或远程图片。

1.0.7 统一海锚标识：深海蓝圆角底、冰青海锚，由一个 256px 母图生成 EXE 的九种 ICO 尺寸及原生窗口、顶部品牌栏、托盘和快捷控制窗口图标。版本目录内的 Ocean.ico 用于桌面快捷方式，避免沿用旧路径的图标缓存。

右键托盘图标在点击处旁边弹出独立快捷控制窗口，显示实际网关状态、接口地址和版本，提供打开主窗口、启动或停止网关、退出程序。窗口使用中文字体，可获得焦点；点击外部、切换窗口或按 Esc 收起。坐标统一采用 AWT 屏幕坐标，按点击所在显示器的工作区限制位置，支持位于主屏左侧的显示器和顶部任务栏。
