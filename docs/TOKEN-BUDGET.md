# Token 余额概览

Windows 1.0.9 在网关首页增加 TRAE 的余额概览：剩余积分快照、按所选模型预计剩余 Tokens，以及全部供应商通过本网关调用的累计已用 Tokens。

## 开始使用

1. 登录 TRAE 账号，在首页点击“刷新积分”。
2. 在“估算模型”选择模型，或粘贴模型页复制的完整 `trae/模型名` ID。这里的选择只控制估算，不会改变客户端实际调用的模型。
3. 点击“配置换算”，填写有依据的“每积分可用 Tokens”和“依据 / 测量条件”。每个模型分别保存，切换到未配置模型时显示“暂无法估算”。留空系数并保存可取消该模型的估算。
4. 根据需要选择余额来源。预计值按照所选来源的已知余额与参考系数计算，收到该来源的新余额后随积分增加或减少。

没有通用、已验证的兑换比例，软件不预置换算系数。模型的积分倍率（例如 0.16×）不是 Tokens/积分，不能直接填进来。参考系数可采用有完整计费规则的已验证数据，或同模型、同账号权益和相同使用条件下的多次测量：总 Tokens ÷ 实际消耗积分。测量期间应排除签到、充值、退款、过期和其他客户端使用；整数积分的舍入也会影响结果。输入输出比例、缓存命中、会员和时段变化都会改变实际结果，请及时校正参考值。

## 两种余额来源

- **权益包参考余额**：通过积分刷新接口获得，签到、充值和权益到期等变化在同步后显示。可能包含其他通道权益；不保证等于当前模型真正可用的积分，也不一定立即反映 SOLO 对话消耗。
- **最近对话余额**：来自对话流中的计费回报，更适合观察该通道消费。点击“刷新积分”不会覆盖它；签到、充值或外部消费需要等待下一次计费回报才能同步。

两种来源分别保存，不相加、不互相覆盖。重启后恢复最近的快照。旧版账号余额缺少观察时间，会明确显示更新时间未知，而不会伪装成刚刷新。

## 统计范围与未知值

积分与预计剩余 Tokens 只汇总已启用、未因凭据失效禁用的 TRAE 账号，供应商本身也必须启用。其他供应商的积分或百分比不并入 TRAE 余额。余额未知的账号不按零余额处理，界面注明已知账号数和合计范围。刷新失败保留上次数据并提示失败；“最早余额更新时间”表示所汇总快照中最旧的数据时间。

预计剩余 Tokens 是参考值，不是上游承诺、实际预分配额度或模型上下文窗口。积分可能在尚未用完时到期，因此估算也不保证这些 Tokens 最终都能消耗。

累计已用 Tokens 来自上游 usage 回报，覆盖所有供应商经过本网关的调用；缺少 usage 的调用无法完整统计。它不随积分收入改变。清空调用记录会重置这一累计用量，但不会删除 Token 换算配置和余额快照。

参考：TRAE 官方 [套餐与计费](https://docs.trae.cn/ide_plans-and-billing)、[模型折扣说明](https://docs.trae.cn/ide_limited-time-discount-for-builtin-models)。
