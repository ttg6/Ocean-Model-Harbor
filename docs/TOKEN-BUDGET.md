# Token 自动计算

Windows 1.0.10 默认开启“自动计算（实测）”，无需填写 Tokens/积分。

## 怎么使用

1. 从旧版托盘退出程序，再打开新版 Ocean 模型港，正常登录并通过网关使用 TRAE 模型。
2. 首页的 Token 概览会自动采集正常调用数据。未选择模型时，首次完整调用后自动选中该模型；也可以选择要查看的模型。
3. 首次带用量和计费回报的完整调用建立余额基准；后续完整调用累计至少 2 积分扣减后，会自动显示预计剩余 Tokens。余额不变或只扣 1 积分的调用会累积，以减小整数积分舍入的影响。
4. 点击“测算详情”，查看各账号的实际 Tokens、积分扣减、计算比例和配对调用次数。

软件不会为测算主动发起额外模型请求。没有足够数据时显示“采集样本中”，继续正常使用即可。更换未测算的模型、时段或账号时，也需要相应样本。

## 计算方法

每个账号单独计算：有效调用的 Tokens 合计 ÷ 同期实际扣除的积分，得到参考 Tokens/积分；再乘以该账号当前余额。最终汇总已有样本且可用的 TRAE 账号。缺少余额或样本的账号不会套用其他账号的比例，界面提示合计覆盖范围。

按账号、模型和忙闲时段分别保存。忙时为北京时间 08:00–22:00，闲时为其他时段；只使用近期 24 小时内同一时段的最近 20 组样本。重启保留测算结果，但不沿用停机前的余额基准。

正常完成且同时回报用量和积分余额的调用才可测算。同账号并发、失败、中断、缺少字段、积分增加、间隔超过 10 分钟或跨越时段边界等情况会打断测算。签到/任务操作会重建基准。不同模型未扣整积分的尾数不合并。

同一账号在其他客户端消费可能无法识别。输入输出比例、缓存、会员权益和上游调价也会影响未来可用量，因此结果是参考估算，不是官方固定兑换规则或承诺额度。

## 余额来源

默认使用“最近对话余额”，与自动测算同口径。签到、充值和外部消费在下一次计费回报后反映。

“权益包参考余额”由积分刷新接口获得，可能包含其他通道权益，也不一定立即反映 SOLO 消费；用它估算时仅供参考。两种余额分别保存，不相加或互相覆盖。

## 高级参考与累计用量

1.0.9 的手动参考值继续保留。确有可靠规则时可以关闭“自动计算”，再使用“高级参考”；默认自动模式不读取手填比例。

累计已用 Tokens 只统计经过本网关且上游回报 usage 的调用，包含全部供应商。清空调用记录会重置累计值，但不会删除自动测算样本、余额快照或高级参考设置。
